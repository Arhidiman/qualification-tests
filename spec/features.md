# ⚙️ Features приложения

## 1. Выбор теста

* отображение списка тестов
* каждый тест загружается из JSON
* пользователь может выбрать тест для прохождения

---

## 2. Прохождение теста

* поддержка:

  * одиночного выбора
  * множественного выбора

* отображение вопросов

* выбор ответов

* возможность изменять ответы

---

## 3. Пагинация

* максимум 10 вопросов на страницу
* переключение между страницами
* сохранение выбранных ответов при переключении

---

## 4. Завершение теста

* подсчёт результатов:

  * количество правильных ответов
  * процент правильных ответов

---

## 5. Сохранение результатов

* каждая попытка сохраняется в Local Storage
* сохраняется:

  * дата
  * результат
  * количество правильных ответов

---

## 6. История результатов

* список всех попыток
* отображение:

  * количества попыток
  * успешных попыток
  * результатов по каждой попытке

---

## 7. Статистика

* общее количество попыток
* средний результат
* лучший результат

---

## 8. Работа с данными

* каждый тест хранится в отдельном JSON-файле
* структура данных должна быть универсальной
* возможность легко добавлять новые тесты без изменения кода

---

## 9. UX требования

* простой интерфейс
* быстрый отклик
* сохранение прогресса при навигации между страницами

---

## 10. Расширяемость

* возможность добавить:

  * таймер
  * категории тестов
  * фильтрацию
